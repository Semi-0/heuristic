# Language context

The guide and examples are copied from the local Lain source tree at `projects/datalog-research/propagators/doc/` for this experiment. Their internal implementation links refer to that upstream tree, not to files provided by this small harness repository.

`tools/build_live.py` places the guide and `soul-refined.lain` into explicit environment bindings. `describe-environment` includes a document index plus their full text at the model's inference boundary. Live capability signatures and observed compiler diagnostics take precedence over conceptual examples.
