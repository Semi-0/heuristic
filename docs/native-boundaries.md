# Native boundaries in the migration

This inventory describes the current draft, not completed acceptance. Host extensions do not preseed cells or install custom compiler activation/installation hooks; native facilities declare primitive or effectful propagators. `integration.lain`, `lib/ports.lain` and `lib/model.lain` own dependency assembly, source and model networks. Live capability/port bundles use `struct` and `slot`; queued immutable data remains in TTMS bases. Initialization is a primitive propagator wired by Lain to the cell it declares; it no longer registers a session transition. Every exported facility has a distinct extension identity and an explicit import in `integration.lain` or is supplied as an external capability endpoint. The convenience installer assembles those extensions.

| Boundary | Contract and justification | Mutation |
| --- | --- | --- |
| `empty-env`, `lexical-child`, `env:slot`, `extend-env` | Construct native lexical references and binding-cell contributions; preserve compiler identity and frame declarations. | None |
| `lexical:bindings`, `lexical:parent` | Read one frame and its parent; expose availability, premises, cell and frame identity. The metadata field is `:premises`; `:support` is reserved for a TTMS layer. Lain chooses traversal and shadowing. | Immutable network publication |
| `value:kind`, `value:slots` | Report callable/compound/scalar kind and immediate field metadata. Lain chooses recursive descriptions and cycle handling. | Immutable network publication |
| `data:record`, `data:list`, `data:get`, `data:merge`, `data:empty?`, `data:integer?`, `data:equal?` | Immutable records/lists are TTMS base values. Pure primitives preserve input support; scalar constants stay primitive. Structural data equality shares that publication contract. | None |
| `data:snapshot`, `data:unpack` | Resolve finite connected values and bridge immutable records with open compounds. Snapshot equality controls publication versions, not domain selection. | Immutable network publication |
| `cell:reference`, `cell:value`, `cell:input` | Connect explicit cell identities; `inputs-of` is now a Lain composition using the model’s `:inlet` slot. They do not select inference or compiler policy. | Immutable declarations |
| `source:read-next` | Parse one form without rewriting admitted source. Explicit stream completion distinguishes final atoms, incomplete suffixes and malformed forms. | Invocation-local reader cursor only |
| `admission:declaration` | Construct a targeted source declaration; never install it directly. Current wiring carries the model premise; round and consumed-context premises remain incomplete. | None |
| `source:initialize` | Initialize the Lain-declared output once with a TTMS source datum when its initial input becomes available. It neither allocates the target nor overwrites an initialized source. | Immutable network publication |
| `and`, `or`; builtin `not` | Boolean primitives. A deciding input suffices for `and`/`or`; otherwise all operands are required. Watched premise states remain distinct from result support, so witness withdrawal and recovery are preserved. | None |
| `session:feedback`, `session:admit` | Register connected declarations. Immutable session advancement compares versions or admits one form and publishes a receipt. The receipt must already be declared and wired; missing receipts are rejected before admission. | None inside transformations |
| `session:export` | Register four connected arguments: interface family, identity, kind and existing cell reference. Read available declarations independently; reject conflicting identities. Allocates no source cells. | Immutable network declaration |
| Open-session host | Serialize external publication and commit immutable session snapshots. Validate exported ingress, run identity and message identity. | Authoritative session owner |
| `transport:stream` | Execute the request selected by Lain; publish chunks, completion or failure to its explicitly wired event reference. | One external request thread, cancellation/completion flags and event sequence counter |
| `message:deliver` | Publish generated message content to its wired delivery reference with an invocation identity and acknowledge delivery. `message-to-user` is the Lain closure connecting this capability to a model. | Authoritative publication and dependency lifecycle |
| Editor owner catalog | Existing discovery, attachment and generation machinery; narrow user-message operation for opted-in external owners. | Existing view/owner registry |

`resume-model!` publishes an identified command through the model’s exported control port. `model:command` in Lain selects the resume transition and records consumption without resetting the turn or budget. Identical command replay is harmless. The unused host `admit-source!` helper, which manufactured receipt cells, has been removed. Event ingress retains immutable logs but does not yet enforce the required end-to-end 256-pending-event backpressure. These are explicit remaining gaps.

Focused tests cover immutable compare-and-advance, selected Lain feedback without a host, parser/admission components, direct source initialization, Boolean truth tables and premise withdrawal/recovery, Lain resume commands, observation withdrawal/recovery, import identities, and shared editor/headless ingress. Full transport lifecycle, supported admission recovery, model independence, and canonical coded conversation remain unverified.

The existing `resource_queue.clj`, `resource_stream.clj`, and `resource_environment.clj` files are unused compatibility remnants. Their removal is deferred until the replacement's acceptance tests pass, as required by the migration plan.

`Frozen` and the observation `Snapshot` wrapper have been removed. Existing lexical reference records (`Environment` and `Contribution`) are carried as TTMS bases. Source identity is the cell actually declared by Lain, not an identity computed by the harness host. The standard primitive declaration installer allocates its call ports; the harness does not supply an alternate installer or allocate additional seeded sampling cells.

Model/user interfaces are now declared inside Lain with `session:export`. The generic session API combines these with any existing static interface declarations and checks resolved cells exist. Native IO publishes to references wired through capability arguments. The host no longer manufactures model/user source files or model-specific interface maps. Reading or attaching a view does not initialize a second model.

Focused capability tests exercise transport chunks/completion and explicit delivery through a Lain struct, including delivery deduplication and verified owner cleanup. Normal transport completion no longer interrupts its own cleanup receipt wait. These component checks do not establish complete conversation lifecycle acceptance.
