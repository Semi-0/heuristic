## Useful transfer, with limits

The model can leave behind a computational relationship that the next request actually invokes. It can also decline abstraction when primitive composition is simpler. Keep the first behavior observable through retained identity and connections; do not infer it solely from a planning label or a repeated correct answer.

The environment description is a capability and evidence boundary: role/task first, then readable language and operator descriptions/examples, identified inputs, existing computations, and actual diagnostics. Only the Lain-produced request is sent to transport. Thinking, source history, actual replies, and delivered-message history remain distinct. Unknowns and contradictions should be explicit observations, not recursively expanded full environment dumps.

Partial evaluation means a relation can be installed while a needed value is unavailable and complete later when that value arrives. It does not mean every missing prerequisite automatically becomes a premise veto. In the high-level list tests, the premise endpoint is declared, a supported producer is admitted, and then function source is admitted, matching the original fact-before-consumer setup without cell seeding.

For Tsuki, compare raw contribution storage with user-visible projections and accessor outputs. Our older raw-list assertions looked like lost support or failed withdrawal, but compiled Lain consumers behave correctly. This is directly relevant to distinguishing alternative-justification elements from a selected witness support set. It does not prove that Tsuki's OR semantics, writer supersession, nogoods, or ledger replay are equivalent to Lain TTMS.

Keep source admission, ready outputs, numerical correctness, and required premise links separate. Our current control compiles the valid prefix and correctly reports an invalid suffix, yet fails to request a repair. Conversely, the historical missing question/rule connections really were absent from generated source; merely exposing a premise in an environment does not attach it to a result.
