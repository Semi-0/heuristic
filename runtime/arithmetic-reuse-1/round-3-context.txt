## language-cell
Lain uses prefix arithmetic and connected expressions. (define name expression) binds a cell. + adds, - subtracts, * multiplies, / divides. A nested call composes computations. (-> value target) connects cells. (struct :key cell) exposes a cell as a named slot. ((slot :key) object) accesses that slot, including as a connection target. text:format constructs text from a template and connected values. Unknown cells wait for information.
